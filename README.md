# FreshSip – Juice Store Mini Project

## CWS LA-II Mini Project
A simple first-year web design project made using HTML, CSS and Bootstrap.

### Pages
1. Login
2. Home
3. About Us
4. Explore Juices
5. Daily Special

### Technologies
- HTML5
- CSS3
- Bootstrap 5
- Figma (for wireframe/UI/prototype)
- GitHub (for repository)

### How to run
1. Extract the ZIP.
2. Open the project folder.
3. Double-click `login.html` or `index.html`.
4. Navigate through the pages using the menu.

### Figma plan
Create 5 frames with the same page names:
Login, Home, About Us, Explore Juices, Daily Special.

Prototype connections:
Login → Home
Home → About Us
Home → Explore Juices
Home → Daily Special
About Us → Explore Juices
Explore Juices → Daily Special

### Viva points
HTML creates webpage structure.
CSS provides styling.
Bootstrap provides responsive layout and ready-made components.
Figma is used for UI design and prototype navigation.
GitHub is used to store and share the project source code.

## Note
The login and order buttons are demonstration features only; this project does not use a real database or payment system.
