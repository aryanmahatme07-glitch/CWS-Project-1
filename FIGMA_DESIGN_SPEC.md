# FreshSip Figma Design Specification

Use these 5 frames in Figma:

## 1. Login
- FreshSip logo
- Email field
- Password field
- Login button
- Continue as guest

Prototype: Login button → Home

## 2. Home
- Navbar
- Hero section: Fresh Juice. Fresh Life.
- Explore Juices button
- Today's Special button
- Three popular juice cards
- Feature section

Prototype:
Explore Juices → Explore Juices
Today's Special → Daily Special
Navbar links → respective pages

## 3. About Us
- About FreshSip
- Short description
- Four feature cards
- Explore Our Menu button

Prototype: Explore Our Menu → Explore Juices

## 4. Explore Juices
- Six juice cards
- Name, description, price and Order Now button
- Navigation bar

## 5. Daily Special
- Today's Special label
- Mango Magic
- ₹89
- Order Now button

### Suggested Figma style
Primary: Green
Background: Very light green/white
Cards: White with rounded corners
Font: Inter or Poppins
Use simple fruit emojis/icons if image assets are not required.
